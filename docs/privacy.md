# 権限とプライバシー

MarginClipはアカウントやクラウドサービスを使用しません。メモ、画像、元URL、タイトル、取得した記事本文は、このChromeプロファイル内のIndexedDBに保存します。利用状況の解析、広告SDK、外部フォント、遠隔コードは使用しません。

## Chromeの権限

| 権限 | 使用目的 |
|---|---|
| `sidePanel` | Webページの横でエディタを表示する。 |
| `tabs` | 現在のウィンドウのアクティブなページのURL・タイトルとページ移動を検出する。 |
| `scripting` | パネルで対象としているページに記事抽出コードを実行する。 |
| `downloads` | 指定した保存先にZIPやJSONをダウンロードする。 |
| `unlimitedStorage` | 画像付きメモを拡張のIndexedDBに保存する。実ディスクの空き容量は必要。 |
| `http://*/*`、`https://*/*` | ページ切り替え後にも記事を抽出し、メモのリモート画像を取得する。 |

インストール時に全サイトのデータへのアクセスが表示されます。パネルが開いているとき、そのウィンドウの対象ページから記事を取得するために使用します。常駐するcontent scriptは登録していません。パネルを閉じている間に記事の巡回・収集は行いません。

クリップボードの読み取り権限は要求しません。ユーザーの貼り付け操作で渡された画像・テキストだけを使用します。

## 外部通信

メモや記事本文を外部サービスへ送信しません。記事画像は元URLをMarkdownに保持するだけで、ZIP保存時に拡張から画像をダウンロードしません。保存後にMarkdown対応アプリで記事画像を表示すると、そのアプリから配信元へのアクセスが発生します。

外部画像URLを含むメモの表示と、メモの画像をZIPへ同梱する処理では、画像の配信元にリクエストが発生します。ZIPの画像取得にはCookie・認証情報を付けず、リファラーも送信しません。相手のサーバーには通常の画像リクエストとしてIPアドレス等が伝わります。

記事は既にブラウザが表示しているDOMから読み取ります。有料記事の制限解除や、ログインしていない状態の本文取得は行いません。メモ画像の取得が拒否されたときは元参照を保持し、警告を示します。

## 保存物の管理

バックアップJSONにはメモ、貼り付け画像、記事本文、閲覧URLが含まれます。ZIPにも記事とメモが入ります。ファイルは暗号化されていません。個人情報を含むファイルは自分で適切な場所に管理してください。

拡張のアンインストールはブラウザ内のメモ・画像の削除につながります。ダウンロード済みのファイルは拡張を削除しても残ります。削除前にバックアップを取得してください。
