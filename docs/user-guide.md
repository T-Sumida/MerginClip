# MarginClipの使い方

## ページを読みながら書く

HTTP/HTTPSのWebページを開き、拡張のMarginClipアイコンを押します。パネル上部には対象ページのタイトルとURL、本文の取得状況が表示されます。下の「MY NOTES」でメモを編集します。Webページは通常どおりスクロール・操作できます。

入力のたびにメモと貼り付け画像をこのChromeプロファイルのローカルデータベースへ保存します。「✓ 保存済み」が保存完了の目印です。サイドパネルを閉じ、後で同じページを開いても復元されます。保存エラーが表示された場合はパネルを閉じる前に退避・バックアップしてください。

ページを移動したりタブを切り替えたりすると、表示中のページのメモに自動で切り替わります。別のChromeウィンドウでは、そのウィンドウの閲覧ページが対象です。

## Markdownの入力

編集欄は常に整形表示されるWYSIWYGです。ソースとプレビューの切り替えはありません。書式ボタン、Markdownの入力ショートカット、Markdownテキストの貼り付けが使えます。

| 入力・操作 | 結果 |
|---|---|
| 行頭で `# ` / `## ` / `### ` | 見出し（末尾の空白まで入力） |
| `**太字**` / `*斜体*` | 太字・斜体 |
| 行頭で `- ` / `1. ` | 箇条書き・番号付きリスト |
| 行頭で `> ` | 引用 |
| `` `コード` `` | インラインコード |
| 行頭で ` ``` ` を入力 | コードブロック |
| 文字を選択して ↗ ボタン | リンクの設定・解除 |
| `[表示名](https://example.com)` を貼り付け | リンク |
| Markdownテキストを貼り付け | 対応する書式をまとめて反映 |

リンクはHTTP/HTTPSに対応します。空の選択範囲でリンクを設定するとURL自体を挿入します。入力したURLは自動でリンクになります。リストや引用から出るには空行でEnterを押します。コードブロックから出るには末尾で下矢印、またはCtrl+Enter（MacではCmd+Enter）を使います。

太字はCtrl+B、斜体はCtrl+I、元に戻すはCtrl+Z、やり直しはCtrl+Shift+Zです。MacではCtrlの代わりにCmdを使用します。ページが切り替わると編集履歴を分離するため、元に戻す操作が別ページの内容に影響することはありません。

一般的なMarkdownの基本書式が対象です。表・タスクリスト・数式・脚注・任意HTMLの完全な再現は対応範囲に含みません。特殊なMarkdownを貼り付ける場合は結果を確認してください。

## 画像

- 画像をクリップボードにコピーして、メモ欄でCtrl+V（MacではCmd+V）。
- ツールバーの画像ボタン（▧）から画像ファイルを選択。
- 画像ファイルをメモ欄にドラッグ＆ドロップ。

PNG・JPEG・WebP・GIF、1枚8MB以下に対応します。画像はメモ内に表示され、貼り付け画像の実体もローカルに保存されます。画像を選択してDeleteまたはBackspaceで削除できます。Webページから画像をコピーする場合、ブラウザの「画像をコピー」を使ってください。画像URLだけをコピーした場合は画像ファイルの貼り付けにはなりません。

## 記事とメモを保存

「記事とメモを保存」を押し、ZIPの保存先を選びます。記事はReadabilityで本文を抽出し、Markdownに変換します。著者・公開日時はページ側に情報がある場合に付加します。

```text
MarginClip-記事タイトル-日付.zip
├── 20261010_001234_記事タイトル_article.md
├── 20261010_001234_記事タイトル_note.md
└── assets/          メモに含まれる保存した画像（画像がある場合）
```

Markdownのファイル名は `{日時情報}_{記事タイトル}_{article または note}.md` です。日時情報は保存開始時のローカル日時（端末のタイムゾーン）を `YYYYMMDD_HHmmss` で表し、記事とメモに同じ日時・記事タイトルを使います。ファイル名に使用できない文字は `-` に置き換えます。記事を取得できない場合は対象ページのタイトルを使います。ZIPにはこの2つのMarkdownと、保存したメモ画像だけを含め、READMEやmetadataファイルは出力しません。

ZIP全体を展開し、`_article.md` または `_note.md` で終わるファイルをObsidian等のMarkdown対応アプリで開いてください。`assets` フォルダはMarkdownと一緒に移動します。記事とメモはそれぞれ独立したファイルです。

記事中の画像は `![画像](元URL)` のMarkdown参照を保持します。記事画像のダウンロードや `assets/` への置き換えは行いません。Markdown対応アプリで画像を表示するには、ネット接続と配信元へのアクセスが必要です。リンク先の削除や認証・参照制限によって表示できなくなる場合があります。

メモに貼り付けた画像はローカルファイルに変換して同梱します。メモ中のMarkdownのリモート画像は取得を試みます。同じ画像URLが記事とメモの両方にある場合も、記事側は元URLのまま、メモ側だけ `assets/` を参照します。メモのリモート画像は認証なし・Cookieなしで取得するため、ログイン必須、取得禁止、タイムアウト等では保存できない場合があります。その場合はMarkdownの元URLを保持し、保存開始後の画面に警告の詳細を表示します。貼り付け画像の同梱に失敗した場合は、成功扱いにせず保存エラーを表示します。

メモ画像の取得は1枚15秒、1枚8MB、リモート画像は最大60枚、Markdownと同梱画像の合計は64MBまでです。SVGは同梱対象外ですが、記事画像のSVG参照は元URLのまま保持します。メモに画像が多い場合は保存に時間がかかります。

記事本文はそのページで初めて取得した内容をメモとともに保持します。動的に記事が更新された場合、遅延読み込みの内容を表示した場合、再取得したい場合は「↻ 再取得」を押してください。取得失敗時は以前の記事本文を保持します。記事を特定できないページでは本文領域からの抽出となり、警告が表示されます。本文を取得できない場合もメモと元ページ情報は保存できます。

## URLの扱い

- `https://example.com/article#section1` と `#section2` は同じメモ。
- `?id=1` と `?id=2` は別のメモ。
- クエリの順序、末尾の `/`、HTTP/HTTPSの違いは保持。
- `utm_source` などの追跡用パラメータも削除しません。
- 同じURLで画面だけが変わるサイトではメモは共有されます。「再取得」で記事本文を更新してください。

## 保存済みメモを開く

右上の一覧ボタンを押すと、更新日の新しい順でメモが表示されます。タイトル・URL・メモ本文で検索できます。

一覧から開いたメモは「SAVED NOTE」と表示され、閲覧ページが移動してもそのメモを編集し続けます。「閲覧中のページへ戻る」で自動追従に戻ります。保存済みの本文があるため、そのメモは元サイトを開かずにZIP保存できます。

## バックアップと復元

メモ一覧の「全メモをバックアップ」で、全メモ、記事の取得結果、貼り付け画像をJSONに保存します。ZIPは記事・メモを読むための出力、JSONはMarginClipへ戻すためのバックアップです。

「復元」でMarginClipのJSONバックアップを選択します。既存のURLのメモは上書きせず、未登録のURLのメモだけ追加します。対応するバックアップはversion 1、100MB以下です。復元後はメモ一覧から開いてください。

別ウィンドウで同じメモが更新されると、古い内容による上書きを防ぐため編集を停止します。「編集内容を退避して最新版を開く」は編集内容のJSON保存を開始し、ローカルの退避メモも作成してから最新版を表示します。退避メモはタイトル末尾に「（退避）」が付き、元メモと区別する管理用クエリが付いたURLで登録されます。空き容量不足時はローカルの退避に失敗する場合があるため、ダウンロードしたJSONも保持してください。

メモはChromeのプロファイル単位です。クラウド同期はありません。拡張の削除、プロファイルの削除、別プロファイルや別端末への移行の前には必ずバックアップを取得してください。シークレットモードでの利用は初期版の検証対象外です。
