# インストールガイド

[ドキュメント一覧](README.md) · [ユーザーガイド](user-guide.md)

## 必要な環境

Google Chrome 116以降を使用します。組織管理のブラウザでは、拡張の手動読み込みが制限されている場合があります。通常利用にNode.jsは不要ですが、ソースからビルドする場合はNode.js 24とnpmが必要です。

## 配布ZIPを使う

[Releases](https://github.com/T-Sumida/MerginClip/releases)にビルド済みZIPがある場合は、対象バージョンの `MarginClip-<version>.zip` をダウンロードし、ZIP全体を保存場所へ展開します。配布がない場合は次の手順でビルドしてください。

## ソースからビルドする

Git、Node.js 24、npmが使える環境で実行します。

```sh
git clone https://github.com/T-Sumida/MerginClip.git
cd MerginClip
npm ci
npm run build
```

依存パッケージは `package-lock.json` で固定しています。ビルドによって `dist/` が生成されます。GitHubのソースZIPにはビルド済みの拡張は含まれません。

## Chromeに読み込む

1. Chromeのアドレス欄に `chrome://extensions` と入力します。
2. 右上の「デベロッパーモード」をONにします。
3. 「パッケージ化されていない拡張機能を読み込む」をクリックします。
4. `manifest.json` が直下にあるフォルダを選びます。ソースからのビルドは `dist`、配布ZIPは展開した `MarginClip` フォルダです。
5. MarginClipが一覧に表示され、エラーがないことを確認します。
6. ツールバーの拡張機能メニュー（パズルのアイコン）でMarginClipをピン留めします。
7. 通常のWebページを開き、MarginClipのアイコンを押します。

Chromeに読み込むのは `src/` やリポジトリのルートではありません。読み込み元フォルダは移動・削除せず保持してください。サイドパネルの左右位置はChromeの設定で変更できます。

サイトへのアクセス権限は、対象ページの記事抽出とメモのリモート画像取得に使用します。[権限と通信の説明](privacy.md)を参照してください。

## 更新する

1. メモ一覧の「全メモをバックアップ」でJSONを保存します。
2. パネルの「保存済み」を確認して閉じます。
3. ソースを更新した場合は `npm ci`、`npm run build` を実行します。配布ZIPの場合は、同じ読み込み元フォルダの内容を新しい版に置き換えます。
4. `chrome://extensions` のMarginClipにある再読み込み（↻）ボタンを押します。
5. パネルを開き、メモと拡張のバージョンを確認します。

同じ拡張ID・Chromeプロファイルで更新した場合、メモは保持されます。更新時に拡張を削除しないでください。別フォルダを読み込むと別の拡張IDになり、元のメモが見えなくなることがあります。その場合はバックアップを復元してください。

## アンインストールする

全メモをバックアップしてから、`chrome://extensions` でMarginClipの「削除」を押します。アンインストールはブラウザ内のメモ・画像の削除につながります。ダウンロード済みのZIPやJSONは残ります。

## よくある問題

| 症状 | 対処 |
| --- | --- |
| `manifest.json` がない | ビルドして `dist` を選択。配布ZIPは展開して中の `MarginClip` を選択。 |
| アイコンが見えない | 拡張機能メニューでピン留め。 |
| パネルが開かない | Chromeを更新し、拡張を再読み込み。拡張の詳細画面でエラーを確認。 |
| 本文が取得できない | 通常のHTTP／HTTPSページを使い、読み込み後に「再取得」。サイトへのアクセス設定も確認。 |
| メモが切り替わらない | 「SAVED NOTE」の表示時は「閲覧中のページへ戻る」。保存エラー時は編集内容を退避。 |
| 保存できない | 表示された退避ボタンかバックアップで編集内容を保存。空き容量と別ウィンドウでの同時編集を確認。 |
| ZIPの画像が表示されない | メモの画像はZIP全体を展開し、`assets` をMarkdownと一緒に置く。記事画像は元URLへのアクセスを確認。 |

Chromeの設定画面、新しいタブ、Chrome Web Store、PDFビューア、ローカルファイルは記事抽出の対象外です。解決しない場合は[不具合報告](../CONTRIBUTING.md#issueを作成する)の案内に沿ってIssueを作成してください。
