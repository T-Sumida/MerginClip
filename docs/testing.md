# テスト・検証

[ドキュメント一覧](README.md) · [開発ガイド](development.md)

## 自動チェック

```sh
npm ci
npm run check:docs
npm test
npm run build
npm run test:e2e
```

ブラウザの準備後は `npm run check` でまとめて実行できます。

ドキュメント検査はMarkdown内の相対ファイルリンクと画像参照を確認します。外部URLの応答やページ内アンカーは検証しません。

単体テストではURLキー、ファイル名、保存と競合、バックアップ検証・復元、Markdownの往復変換、危険なURLの除去、記事本文・メタデータ・JSON-LD、ZIP内容と画像参照を確認します。

ブラウザテストではMarkdown入力・画像貼り付け・再読み込み、ページ移動・タブ切り替え・履歴分離、書き出したZIPの実体、検索とバックアップ、非対応ページ、複数ウィンドウの競合と退避、大きな画像の保存を確認します。

## ブラウザテストの準備

Windowsではインストール済みGoogle Chromeを自動検出します。Chromeを最新の安定版に更新してください。検出されない場合や使用ブラウザを指定する場合は、実行ファイルのパスを環境変数へ設定します。

```powershell
$env:MARGINCLIP_CHROME_PATH = 'C:\Program Files\Google\Chrome\Application\chrome.exe'
npm run test:e2e
```

Windows以外やインストール済みChromeがない場合は、PlaywrightのChromiumをインストールします。

```sh
npx playwright install chromium
npm run test:e2e
```

Linuxでシステム依存も必要な場合は `npx playwright install --with-deps chromium` を使えます。ブラウザテストには拡張の読み込みとアクション実行を行えるCDPが必要です。対応メソッドがない場合はブラウザを更新してください。

テストは一時プロファイルとローカルHTTPサーバーを使用し、通常利用のChromeプロファイルを変更しません。拡張の通常利用にPlaywrightは不要です。

## ブラウザテストの境界

拡張アイコンのアクションをCDPで実行し、実際のSIDE_PANELコンテキストの起動、対象ページのタイトル・記事取得を確認します。ChromeネイティブのパネルはPlaywrightのPageとして公開されないため、編集やダウンロードの詳細操作は同じ拡張オリジンのページで確認します。Chrome API・IndexedDBは実体を使用します。

画像・Markdownの貼り付けはpasteイベントを生成して検証します。OSのクリップボードや実際のマウスによるドラッグ操作は手動確認の対象です。

## リリース前の手動確認

- 通常のWebページでアイコンからパネルを開き、メモ入力・画像の貼り付け・ファイル選択・ドラッグ＆ドロップを確認する。
- ページ移動、タブ切り替え、パネルの閉じ直しでメモが保持されることを確認する。
- ライト／ダーク表示、狭いパネル幅、キーボード操作を確認する。
- ZIPを展開してMarkdownアプリで開き、記事画像は元URL、メモ画像は同梱ファイルを参照することを確認する。
- 全メモのバックアップを別のテスト用プロファイルへ復元する。
- 配布ZIPから新規インストールし、同じフォルダへの更新も確認する。

## 対応範囲

Chrome 116はAPI上の最低バージョンです。初期実装の自動検証はWindows、Node.js 24.15.0、Chrome 154.0.8037.95で2026年10月10日に実施しました。最低バージョンの実機、macOS・Linux、シークレットモード、企業管理のChromeは未検証です。CIの実行結果は各コミットのGitHub Actionsで確認してください。

HTTP／HTTPSの一般的な記事ページと基本Markdownを対象にします。認証・有料記事の制限解除、別オリジンのiframe内部、画像だけの本文には対応しません。サイト構造や遅延読み込みによって「再取得」が必要な場合があります。

トランザクション完了前の強制終了では最後の変更が残らない可能性があります。記事画像は外部URLなので、ネット接続や配信元の公開状態に依存します。利用上の詳細は[ユーザーガイド](user-guide.md)を参照してください。
